## Engineering principles

| Principle | What it means to me |
| --- | --- |
| **Start with the problem** | Understand the domain and model the data before writing endpoints. |
| **Keep responsibilities clear** | Thin controllers, focused services and infrastructure that stays replaceable. |
| **Build for real usage** | Authentication, validation, error handling, logs and documentation are part of the product. |
| **Make it easy to run** | A good project should be understandable and runnable by another developer. |
